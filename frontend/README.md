# Frontend (Expo)

Bu klasörün giriş noktası [App.tsx](App.tsx) dosyasında bulunan React Native chat ekranıdır.

Tek tıkla başlatma dosyası artık bu klasördeki Expo uygulamasını açar; eski statik HTML sunucusu kullanılmaz.

İlk çalıştırmada bağımlılıklar otomatik kurulabilir. Gerekirse elle kurulum:

```bash
cd frontend
npm install
npm run web
```
